# Git Field Guide

คู่มือ Git ภาษาไทยแบบละเอียด ตั้งแต่การติดตั้ง, `status → add → commit`, branch และ merge, remote / Pull Request, การแก้ conflict ไปจนถึงการกู้คืนเมื่อเผลอแก้พลาด

## เปิดใช้งาน

เปิดไฟล์ [index.html](./index.html) ในเบราว์เซอร์ได้เลย หรือรัน static server:

```bash
python3 -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

## สิ่งที่มีในคู่มือ

- สารบัญแบบ sticky และ reading progress
- ปุ่มคัดลอกคำสั่ง Git
- โหมดกลางคืนและ responsive layout
- ภาพประกอบ SVG ใน `assets/`
- เนื้อหา 8 บท พร้อมตัวอย่างคำสั่งที่ใช้จริง
